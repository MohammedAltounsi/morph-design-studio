# Morph — Design Studio

**Let's Morph.** A bold, bilingual (Arabic / English) brand site for a creative studio — dark, iridescent, and built to make a first impression.

![Morph hero](screenshots/hero.png)

## Highlights

- **Statement hero** — full-bleed 3D iridescent glass with an oversized "LET'S MORPH!" headline
- **Bilingual by design** — Arabic and English side by side (`خدماتنا — Our Services`), right at home in the GCC market
- **Sections** — Home · About · Services · Projects
- **Services** — Marketing (خدمات التسويق), Events (خدمات الفعاليات), and more
- **Responsive** — tuned for desktop and mobile
